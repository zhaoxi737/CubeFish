# scripts/audio — 方块鱼 / CubeFish 宣传片配乐与音效

全部音频都是**纯代码数学合成**：没有第三方素材、没有 ffmpeg、没有 numpy、没装任何 npm 包。
WAV 头是手写的（44.1 kHz / 16-bit / stereo PCM），所有声音 = 方波 / 三角波 / 正弦 / 白噪声 +
ADSR 包络 + 简单滤波 + 延迟 / 压缩 / 软饱和。

- **确定性**：不使用 `Math.random()`，噪声来自 `mulberry32(0xc0bef15)` 单条序列。
  同一条命令跑两次，10 个 wav 的 SHA-256 完全一致（已验证）。
- **时间轴**：150 BPM → 1 拍 12 帧 = 0.4 s，1 小节 48 帧 = 1.6 s，全片 38 小节 = **1824 帧 = 60.8 s**。

---

## 一、怎么生成 / 怎么自检

```powershell
# 生成 bgm + 9 个音效（约 2 秒）
node scripts/audio/make-audio.mjs

# 自检：格式、时长、峰值、RMS、分段响度、音效规格（只读，不改文件）
node scripts/audio/check-audio.mjs
```

`make-audio.mjs` 会自己创建目录并覆盖写入产物；`check-audio.mjs` 只读取、退出码 0/1。

## 二、编曲说明

- 调性 **A 小调**，和弦循环 **Am – F – C – G**，每个和弦 **2 小节**（96 帧）；全片 38 小节 = 19 个和弦段（4.75 轮循环）。
- 声部：
  - **方波主旋律**：占空比 25% 脉冲，两层 ±6 cent detune 左右分开，长音带颤音；S4 高音层用正弦 + 三角波 + 附点八分延迟。
  - **三角波贝斯**：八分音符 riff（root / 八度 / 五度），附一层很轻的方波咬字层。
  - **正弦 sub**：每段和弦一根低音（A1/F1/C2/G1），S2 轻量化段加重。
  - **白噪声鼓组**：正弦扫频底鼓（46–154 Hz）、带通噪声军鼓 + 185 Hz 鼓腔、高通噪声踩镲；踩镲左右交替摆位。
  - **琶音（arp）**：8-bit 脉冲 8 分音符，S2 变薄变亮、S4 滤波器渐开、S5 逐渐放慢。
- 效果：0.3 s（附点八分）ping-pong 延迟、母线软拐点压缩、tanh 软饱和、M/S 轻微展宽、一阶高通去直流。

### 段落与帧号（30fps）

| 帧 | 小节 | 事件 |
|---|---|---|
| 0 | 0 | 只有 arp + pad，**无鼓**；6 帧淡入 |
| **70** | 1.46 | 像素鱼拼合：52–70 帧上升音，70 帧落定（低频落点 + Am 和弦 + 高频闪烁） |
| **144** | 3 | **drop**：鼓组 + 贝斯 + 主旋律进入（底鼓 4/4、反拍军鼓、八分踩镲） |
| 480–576 | 10–12 | 断点：鼓全部撤掉，只留 arp + sub（S2 轻量化，明显留白） |
| **576 / 672 / 768 / 864** | 12 / 14 / 16 / 18 | 四张功能卡卡点：C / G / Am / F 和弦重击（+ 底鼓 + crash） |
| **960** | 20 | AI 段开始：加高音旋律层、arp 滤波器渐开、上行 pickup |
| 1080 / 1200 / 1320 / 1440 | 22.5 / 25 / 27.5 / 30 | 短促「数据/打字」音型（提前 12 帧有 4 音上行） |
| **1536** | 32 | 结尾：鼓停，只剩和弦 + arp 渐慢（8 分 → 附点 8 分 → 4 分 → 2 分） |
| **1776** | 37 | 最后一次品牌重击（低频冲击 + C 和弦 + 金属泛音），余韵到 1824 |
| 1784–1824 | — | 40 帧淡出 |

## 四、怎么改 BPM

`make-audio.mjs` 顶部：

```js
const BPM = 150;
```

派生量：`BEAT_FRAMES = round(60 / BPM * 30)`，`BAR_FRAMES = BEAT_FRAMES * 4`。
150 BPM 时 1 拍 = 12 帧、1 小节 = 48 帧，`48 × 38 = 1824` 正好等于全片长度。

> ⚠️ **全片时间轴是按帧锁定的**（1824 帧 @30fps），38 小节只在 150 BPM 成立。
> 直接改 BPM 会让小节线相对画面漂移，段落边界（144/480/576/960/1536…）不再落在小节线上；
> 脚本检测到 `BAR_FRAMES * 38 !== 1824` 会在控制台打印警告。
> 真要改速度，必须同步修改 `video/src/timeline.json` 和每段小节数（见 `docs/PROMO-VIDEO.md`），
> 并核对 `TOTAL_FRAMES` 与各段帧常量。

想改「76 秒版」：按 `docs/PROMO-VIDEO.md`，S3 每卡 +48 帧、S4 每小段 +24 帧，
相应修改 `TOTAL_FRAMES` 与 `S0..S5` 常量，并把各段帧数/小节数对齐；配乐里旋律数据是按小节写的，会自动跟随。

## 五、怎么改音色 / 混音

- **主旋律音量**：`renderBgm()` 末尾 `playLead(note, 0.075/0.072/0.052)`。
- **琶音音量/亮度**：`renderBgm()` 里 arp 循环的 `gain / cutoff / duty` 分支。
- **贝斯型**：`BASS_RIFF`（8 个八分音符槽位，`null` 为休止）。
- **鼓组**：`addKick / addSnare / addHat / addCrash` 的 `gain`。
- **母带**：`normalize(mix, 0.95)` → `compressBus(...)` → `softSaturate(mix, 1.5)` → `widenStereo(mix, 1.25)`
  → `applyFades` → `normalize(mix, 0.949)`。峰值常量 `PEAK_TARGET = 0.949`、淡入 `FADE_IN_FRAMES = 6`、
  淡出 `FADE_OUT_FRAMES = 40`。
- 改完务必跑 `check-audio.mjs`，确认峰值 ≤ 0.95、时长 1824 帧、分段响度关系没被破坏。

> 注意：`PEAK_TARGET` 取 0.949 是因为 float 峰值乘 32767 再四舍五入写 int16 后可能向上取到 0.9500x；
> 用 0.949 可以保证**实际文件**的峰值 ≤ 0.95。

## 六、验收自检项

`check-audio.mjs` 输出并检查：

1. RIFF/WAVE、PCM、44.1 kHz、16-bit、stereo、byteRate/blockAlign；
2. bgm 时长 = 1824 帧（60.8 s）± 1 帧（当前误差 0 帧）；
3. bgm 峰值 ≤ 0.95、无 ±32767 削波样本、直流偏移可忽略；
4. 打印时长 / 峰值 / RMS / 波峰因数 / 峰值所在帧；
5. 六个段落的 RMS 与峰值，并检查结构关系（主歌 > 前奏、轻量化 < 主歌、功能卡 > 轻量化、结尾 < AI 段）；
6. 9 个音效齐全、时长 0.1–0.8 s（riser 1.6 s 特例）、峰值 ≤ 0.95、无削波。
