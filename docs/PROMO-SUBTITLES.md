## 三、逐段讲解稿（口播用，可选）

> 这是把字幕扩写成一段一段能直接念的稿子，每段对着一处画面。语速按 4~5 字/秒算，长度已经配好画面时长。

### 开场（0:00–0:05）
「想和朋友一起玩 Minecraft，但被版本、模组、Java 折腾到放弃？这个启动器叫方块鱼，它最不一样的地方是——它自己会动手。」

### 一、核心流程（0:05–0:16）
「左边就是现在要玩的实例，一套存档、一套模组、一套配置，互不干扰。
上面切到版本页，原版、Forge、Fabric、NeoForge 全在这，想换随时换。
选好加载器点一下，剩下的下载、解压、装依赖，它自己干完。」

### 二、轻量化（0:16–0:19）
「整个启动器就是一个压缩包，免安装，双击就跑。数据全在你本地，不上传。」

### 三、四个硬功能（0:19–0:32）
「第一，实例隔离——每个实例一套 mods、存档、配置。
第二，下载中心接的是 Modrinth 加 CurseForge 双源，一次搜完。
第三，启动失败不用自己翻日志，它直接告诉你崩在哪。
第四，插件跑在独立进程里，崩了自动回滚，不会把你的启动器一起带走。」

### 四、AI 才是重点（0:32–0:51）
「说一句『帮我装个钠优化』，它自己去搜、自己挑版本、自己装。
崩了？它读日志、定位原因、直接修，最多给你一句『定位到 Iris 旧版本残留』。
缺什么功能，它能自己写一个插件补上，当场装好。
它还记得你上次说过什么，也能同时开几个子助手并行干活。
而且——它能听你说话，也能开口回答你。」

### 收尾（0:51–1:00）
「免费开源，GPL-3.0，Windows 10 和 11 都能跑，现在版本 v0.2.0。
GitHub 搜 zhaoxi737 / CubeFish，或者直接搜『方块鱼启动器』。」

## 四、做讲解时可以直接用的几个结构

| 用途 | 建议 |
|---|---|
| **B站/YouTube 讲解视频** | 用上面的逐段讲解稿做旁白，画面沿用成片，把成片字幕关掉（或换成上屏关键词） |
| **图文教程** | 按 5 个段落分节，每节配一张对应画面 + 一条字幕当标题 |
| **官网/Release 页** | 只用 14 条字幕的精简版：S0 一条 + S3 四条 + S4 五条 |
| **口播短视频（60s）** | 直接用逐段讲解稿，字数 ≈ 260 字，正常语速正好 58~62 秒 |

> 提醒：成片里 S4 的 AI 回复是本地 mock 返回的固定内容，**讲解时不要把它描述成"真实联网对话"**，说「这里用的是演示数据」更稳。
