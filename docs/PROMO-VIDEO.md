# 方块鱼宣传片 · 制作方案与逐帧脚本

> 状态：**正式制作中**（用户已定：横屏 1920×1080 / 60 秒）· 30fps / h264 / AAC
> 原则：**全片程序化渲染**，不用照片轮播；字幕烧在画面上；音效与音乐由代码合成，零版权风险。

## 一、为什么是 Remotion（方案来源）

| 候选 | 结论 |
|---|---|
| **Remotion**（React 逐帧渲染） | ✅ 采用。`frame` 是纯函数，`spring()` / `interpolate()` 就是贝塞尔与弹簧曲线，和我们 UI 的动画语言完全一致 |
| Motion Canvas / Revideo | 备选。偏「解说动画」，做产品 UI 演示不如 React 顺手 |
| AI 生成视频模型（可灵/即梦/Runway） | ❌ 不做主体。文字必乱、UI 必假、不可复现、改一个字要重生成 |
| 剪映 / PR 手工剪辑 | ❌ 违背「不要照片轮播」。手工对齐帧不可维护，改版本号要重剪 |

依据：
- [Remotion License](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md) —— 个人与 ≤3 人公司**免费且可商用**，本项目符合
- [code-video-handbook](https://github.com/feiyuaq/code-video-handbook) —— 写给 AI 的代码生成视频实战手册：`timeline.json` 单时间轴、BPM/起音帧分析、numpy 合成 11 种音效、ffmpeg 互相关测音画偏移（0ms 才算过）

## 三、成片时间轴（30fps，帧号精确）

**配乐 150 BPM → 1 拍 = 12 帧，1 小节 = 48 帧**；所有段落边界都落在小节线上，卡点天然对齐。
总长 **1824 帧 = 60.8s（38 小节）**。想要 76s 版本，把 S3 每张卡加 48 帧、S4 每小段加 24 帧即可，代码只改 `timeline.json`。

| 段 | 帧区间 | 小节 | 时长 | 画面 | 字幕 |
|---|---|---|---|---|---|
| S0 钩子 | 0–144 | 0–3 | 4.8s | 深绿网格 + 像素粒子；18×13 方块鱼飞入拼合（70 帧处落定）、光晕脉冲；标题「方块鱼」上浮 | 「想和朋友一起玩 Minecraft？」→「一个会自己动手的启动器」 |

### 转场与动效规范

- 全局缓动：`spring({damping: 14, mass: 0.7, stiffness: 120})`，长距离位移用 `damping: 20` 防抖
- 卡片入场：`translateY(60px) → 0` + `scale(0.96) → 1` + `opacity 0 → 1`，错开 6 帧
- 录屏卡片：`rotateX(8deg) rotateY(-10deg) → 0`，同时 `scale(0.88) → 1`
- 转场：方块像素 wipe（12 列方块依次翻面 6 帧），不用淡入淡出（太像 PPT）
- 强调：高亮区域描边 `stroke-dasharray` 跑马 + 点击涟漪（3 层扩散环）
- 文字：入场打字机用「每 1.5 帧 1 字」，退场整体 `translateY(-16px)` + 淡出
- **禁止**：任何 `Math.random()`（不可复现），全部用帧号哈希做伪随机

### 字幕规范

- 位置：底部安全区，底边距 **90px**（横屏版式）
- 样式：半透明黑胶囊 `rgba(0,0,0,0.56)` + 1px 白 12% 描边，圆角 22px（超椭圆），内边距 22×44
- 字号 40px，粗体，白 `#F2F7F2`，行高 1.35，最大两行；胶囊内边距 18×36，圆角 18px，居中
- 单条字幕停留 ≥ 45 帧（1.5s），换行按语义切，不按字数切
- 允许「关键词高亮」：品牌绿 `#4ADE80` 加粗，每句最多一处

## 五、录屏管线（保证"不是照片"）

CDP `Page.startScreencast` 抓真实的 Electron 渲染进程，同时用 `Input.dispatchMouseEvent` 驱动点击，另存 `events.json` 记录每个光标的 `(t, x, y, click)`；在 Remotion 里按事件表重绘**设计过的光标 + 点击涟漪**（CDP 抓不到系统光标，正好由我们控制）。

```
scripts/rec/cdp-rec.mjs   # 连 127.0.0.1:<port>/json → ws → 抓帧 + 事件
scripts/rec/drive.mjs     # 场景脚本：home / download / install / launch / ai
out/rec/<scene>/frame_%06d.png + events.json
ffmpeg-static 编码 → video/public/rec/<scene>.mp4（30fps CFR, crf 14, yuv420p）
```

要点：
- 用**独立数据目录** `QDOQMC_USER_DATA=out/demo-data`（复制真实配置并做脱敏：假账号、假路径），既避开单实例锁，也不把人家真实用户名录进去
- **AI 段用 `npm run mock-llm`**（仓库已有的本地假 LLM 服务）：把 demo profile 的 `llmBaseUrl` 指过去，画面是真的、回复是预设的 → 无需 API Key、不烧钱、不联网、每条录制完全可复现
- 脱敏清单：`settings.json` 里的 `playerName` / `apiKey` / `curseforgeApiKey` 全部替换成假值；录制前逐帧检查有没有真实路径
- 录屏按 1600×1000 抓，横屏里正好装进安全区（缩放至 1680×1050 内），不用硬裁
- 只录需要的 8~10 个动作，不要录整段再剪

## 六、质检（不合格不出片）

1. `npx remotion still` 抽 12 个关键帧，人眼过一遍：中文无方框、无溢出、无错位
2. ffmpeg 解码成片 → 抽帧 & 测响度峰值（目标 ≤ 0.95 防削波）
3. 互相关测音画偏移（handbook `check_sync.py` 思路），偏移必须 0ms
4. 成片规格：h264 / yuv420p / 30fps / **1920×1080** / AAC 192k / 时长误差 ≤ 1 帧
5. 主版 `1920x1080`（B 站 / 官网 / GitHub Release）；定稿后如有需要再出 `1080x1920` 竖屏版

## 八、风险

| 风险 | 处理 |
|---|---|
| 录制时界面里出现真实用户名/路径 | 用脱敏 demo profile，录制前跑一遍检查 |

| 合成音乐太"玩具" | chiptune 是主风格，叠一层 pad + 低频 sub 稳住质感；不满意再换免版权曲库 |
| 横屏里界面和字幕抢空间 | 界面录屏占上半 2/3，字幕压底部 90px 安全区，不重叠 |
| 微软雅黑不能嵌入商用视频 | 仅在 Windows 本地渲染展示系统界面，属正常使用；若对外发布有顾虑，换成思源黑体（开源） |
